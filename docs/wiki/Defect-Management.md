# Defect Management

Defects are documented in `defectos.md`.

The workshop includes defects discovered and resolved through TDD, including:

- Negative age initially accepted incorrectly.
- Dead person initially accepted incorrectly.
- Duplicate voter initially accepted incorrectly.

Each defect includes:

- ID.
- Title.
- Description.
- Severity.
- Status.
- Detection phase.
- Related test.
- Resolution.
- Evidence.

All listed defects are resolved in the final implementation and validated by the test suite.
